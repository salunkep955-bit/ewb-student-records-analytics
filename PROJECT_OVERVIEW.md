# Project Overview

**Project:** Student Records Management and Analytics API  
**Prepared for:** EWB Edu Tech Pvt. Ltd. — Python Backend Development Internship  
**Core stack:** Python, FastAPI, SQLite, SQLAlchemy, Pydantic  
**Data analyst features:** KPI summaries, course distribution, age-group distribution, search/filtering, CSV export for Excel and Power BI.  
**Optional AI:** Local Ollama Q&A using aggregate facts.  
**Data safety:** All seeded records are fictional. Do not commit real student records or secrets.
